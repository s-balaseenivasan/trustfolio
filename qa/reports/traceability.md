The chain is `Requirement → UI → API → Logic → Entity → Test → Findings`. A blank column is a
gap in the chain, not a formatting artifact: a requirement with no test cannot regress safely,
and a requirement with no implementation is a feature that was specified and never built.

guarding it, so a regression would ship silently.

- **REQ-DOC-002** — Unredacted originals are stored as PRIVATE media and served only through an authenticated admin route

- **REQ-VER-016** — A bare registration number is not inspectable evidence of registration
